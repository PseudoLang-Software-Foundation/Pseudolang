# PseudoLang for Visual Studio Code

Syntax highlighting for [PseudoLang](https://github.com/PseudoLang-Software-Foundation/PseudoLang) `.psl` files.

Part of the [PseudoLang monorepo](https://github.com/PseudoLang-Software-Foundation/PseudoLang). The TextMate grammar is auto-generated from the interpreter source to stay in sync with the language spec.
